# `docs/`

Development records for Thinkorplace. Apart from `publication/`, everything here
was written during the May 2026 competition and is a historical record: scores,
champion labels and plans reflect what was believed at the time, on hardware,
budgets and concurrency that differ from run to run. For current results, read
the [technical report](../writeup/thinkorplace-report.pdf) and the
[project README](../README.md).

## Historical development records (May 2026)

| Path | Contents |
|---|---|
| [`problem.md`](problem.md) | Formal problem statement written early in development. |
| [`approach.md`](approach.md) | Algorithm description as of mid-May 2026 (the serial cascade pipeline). |
| [`results.md`](results.md) | Development-era per-design scores and champion tables. |
| [`roadmap.md`](roadmap.md) | Submission-week plan. |

| [`handoffs/`](handoffs/) | Dated session-end notes from development sessions. |
| [`gotchas.md`](gotchas.md) | Codebase pitfalls found during development. |
| [`research_principles_for_walls.md`](research_principles_for_walls.md) | Research-strategy notes from early May. |
| [`research/`](research/) | Literature survey notes on congestion models. |
| [`archived/`](archived/) | Status reports and agent instructions that were already stale in May. |
| [`competition/`](competition/) | Competition-era root files: the challenge README with local notes, submission notes, run log, task list, agent instructions, and a cloud run script. |
